# 計画 08: UI の作り込み

## 目的
ユーザーの指摘「UI/UX が安っぽい」への対応。**コードだけで描く（画像は足さない）**。`docs/godot-tips.md` の UI/UX 知見（文字の大きさ・コントラスト 4.5:1 以上・短い Tween）を守る。見た目の最終判断はユーザーが `outputs/share/plan08/` のスクショで行う。

## 仕様の変更

### 1. 背景（デスクトップの壁紙）
- `main.tscn` の背景色を単色から、縦のグラデーション（夕暮れ〜夜。上は `Color(0.10, 0.14, 0.22)`、下は `Color(0.04, 0.05, 0.10)`）に変える
- タスクバー（下の帯。`Color(0.08, 0.09, 0.12)`）と、デスクトップのアイコン風の薄い装飾を 1〜2 個入れる

### 2. タスクバー（下部）
- 画面下に高さ 40px の帯。`Color(0.08, 0.09, 0.12)`
- 左: 時刻（時計。_process で更新。`HH:MM` 形式、毎秒更新）
- 右: Wi-Fi のアイコン（弧 3 本）・バッテリーのアイコン（四角 + 内側の縦線）を `_draw` で描く
- 中央: アプリ名（"Screenlife Horror" または "Screenlife"）

### 3. 通話/配信アプリの窓（メインウィンドウ）
- 角丸のパネル（`draw_rect` で `radius = 8` 風の処理。Godot の StyleBox を使うのが楽）
- 影: パネルの下に 1〜2 px ずらした同じ大きさの暗い矩形
- タイトルバー: 通話/配信名 + 通話時間/視聴者数 + 最小化/最大化/閉じるボタン風の 3 つの点（赤・黄・緑）。押せない（描画のみ）
- 通話のとき: 通話品質のバー（5 本の縦線。音量や ghost alpha に応じて点灯する）
- 配信のとき: `LIVE` バッジ（赤い丸 + 「LIVE」の文字。赤い丸が 1 秒周期で点滅）

### 4. 映像の枠（ビデオ部分）
- 角丸の枠（4px 幅、白っぽい `Color(0.5, 0.5, 0.55)`）
- 左上: `● REC`（赤丸、点滅）+ 時刻（HH:MM:SS、_process で更新）

### 5. チャット
- 各発言を吹き出しに
  - 相手: 左寄せ、薄灰色（`Color(0.25, 0.27, 0.32)`）、角丸、時刻（右下に小さく）
  - あなた: 右寄せ、青み（`Color(0.20, 0.30, 0.45)`）、角丸、時刻
- 既存の `chat_log`（RichTextLabel）の中身を BBCode で組み立てる

### 6. ボタン
- 押下の動き: 0.05 秒で scale 0.95 → 1.0（短い Tween）
- ホバー: modulate を 1.1 倍に（既存の Button なら default style に上書き）
- 影: ボタンの下に 2px 暗い矩形

### 7. 通知のトースト
- 救出成功・失敗のとき、画面下に「+score」/「-point」のような通知を 1〜2 秒表示（浮上して消える）
- 誤警告のとき: 「-1 信頼」のような通知

### 8. コントラスト・文字サイズ
- ヒント文: 16 → 18（ただし _process の hint_age でのフェードは維持）
- 時刻表示: 18 → 20
- チャット: 20 は維持（コントラスト確認）
- 4.5:1 以上のコントラストを `docs/godot-tips.md` の計算で確認

## 実装の順序（影響が大きい順）
1. 背景のグラデーション + タスクバー（広く見える）
2. メインウィンドウのタイトルバー（赤黄緑の点、通話時間）
3. `● REC` + 時刻の映像枠
4. 配信の `LIVE` バッジ
5. チャットの吹き出し化
6. ボタンの押下動き
7. 通知トースト
