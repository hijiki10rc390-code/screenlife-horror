各シーンの既存 2 択に「誤った選択肢」を 1 つずつ追加し、合計 36 個の選択肢を新規追加する。

## 2. 仕様

### 2.1. 選択肢の構造
既存の選択肢と同じ形式:
```json
{
  "text": "<表示テキスト>",
  "chat": "<チャット欄に流すテキスト>",
  "effect": {
    "belief": <数値>
  },
  "next_scene": "<次のシーン id>"
}
```

### 2.2. belief 値の方針
stage1-4 の追加パターンに準拠:
- 正解: +0.03 〜 +0.08
- 誤選択肢: -0.02 〜 -0.05（やや冷たい・無関心・決めつけ系）
- 緊急シーン (urgent_warning): 両方正解だが 3 択目は「...」（無反応 0.0）で chat だけ流す

### 2.3. 3 択目の配置
すべてのシーンで 3 択目を **末尾** に追加（既存 2 択 + 新規 1 つの順序）。

next_scene は既存 2 択と同じにする（同じ遷移先に進める＝先送り or 信頼下げる選択肢）。

### 2.4. キャラの口調
`docs/character-bible.md` に従う:
- 美咲（stage5）: 「〜かしら」「だわ」 — 「気にしすぎかしら」「あり得ないわ」
- 結衣（stage6）: 「えっ何それ」「教えて！」 — 「気にしすぎ〜」「ありえない！」
- 千夏（stage7）: 「ふふ」「そうね」 — 「ふーん」「そうね、気のせいじゃない？」
- 海（stage8）: 「〜じゃん」「〜っす」 — 「ありがと」「おつかれ」
- 蒼（stage9）: 「〜っす」「まじ」 — 「ありがと」「おつかれ」
- 凛（stage10）: 「〜ね」「だわ」 — 「気にしすぎね」「ありえないわ」
