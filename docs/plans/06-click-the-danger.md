# 計画 06: 「危険をクリックする」を核にする（操作の見直し）

## 目的
ユーザーの指摘: 「危険をクリックするゲームじゃなかったっけ？」。核の動詞は「**危険を見つけて、クリックする**」。いまは、通話は「場所を指す → 警告する」の 2 手順、配信は映像をクリックせずコメントのボタンを押すだけ。これを、**危険をクリックした瞬間に警告が出る**（1 手順）に統一する。

## 新しい操作（全ステージ共通）
- **伝え方を選ぶ**: 1・2・3 キー、または画面下のボタンで「伝え方」を選ぶ（選んだものは明るく表示）。選択は変数 `selected_phrase`（0〜2）。既定は 0
- **映像をクリックすると、その場で警告が出る**: 場所を指す操作と警告が、1 回のクリックになる
- Space は、直近にクリックした場所へのやり直しではなく、**何もしない**（誤操作を避ける。`KEY_SPACE` の処理は残してもよいが、`_on_warn` を呼ばない）
- 判定は今のとおり: 人影が映っていて（`_ghost_alpha_at(t) >= SEEN_THRESHOLD`）、クリックが `ghost_box_now()` の中なら当たり。外す・映る前なら誤警告。緩和で消えている間（`_curve_alpha(t) >= SEEN_THRESHOLD` かつ `_ghost_alpha_at(t) < SEEN_THRESHOLD`）は罰しない

## 仕様

### 1. 入口の関数
- `_on_video_click(scene_pos: Vector2)` を作る。`state == PLAYING` のときだけ動く。映像内のクリック位置（`_on_video_input` の `event.position / VIDEO_SIZE * Vector2(SCENE_W, SCENE_H)`）を渡して呼ぶ
  - 通話（`mode == "call"`）: `_set_mark(scene_pos)` → `_on_warn(selected_phrase)`
  - 配信（`mode == "stream"`）: `_set_mark(scene_pos)` → `_on_comment(selected_phrase, scene_pos)`
- 既存の `_on_warn(phrase)` と `_set_mark(pos)` は、**そのまま残す**（テストが使っている）。`_on_warn` の「`has_mark` が false のときのヒント」は、`_on_video_click` 経由では常に印があるので出ない。これは変えない
- `_on_video_input` は、通話・配信どちらでも、左クリックで `_on_video_click` を呼ぶ（いまの `mode == "stream"` で return する行を外す）
- 照準（`marker`）は、クリックした場所に出して、0.4 秒後に消す（誤警告のときは、いまどおり即消す）。救出のときは、人影に向けた印が見えるまま、結果画面が出る

### 2. 配信のコメントにも位置を持たせる
- `_on_comment(i, pos = null)`: `pos` が与えられたとき（クリック経由）、`ghost_box_now().has_point(pos)` でなければ、**映っていても荒らし扱い（誤警告）**にする（ヒント「人影の場所が違った。人影そのものをクリックしよう。」）。`pos` が `null`（既存のテスト・ボット経由）のときは、従来どおり位置を問わない
- クリックして警告コメントが投稿されたとき、チャットの本文は選んだ警告コメント（`warn_phrases[i]`）
- 必要回数（`need_warnings`）を、`warn_window` 秒以内に当てれば救出、は従来どおり

### 3. 伝え方の選択（ボタン・キー）
- **通話・配信とも**、画面下のボタンは「伝え方の選択」になる（押しても警告は出ない。選んだものを明るくする）
  - ステージ1（`use_phrases == false`、伝え方が 1 つ）: 伝え方のボタンは出さない。代わりに、画面下には「話しかける」だけ。ヒントに「怪しいものを、クリック！」
  - ステージ2（`use_phrases == true`）: 「1 後ろ見て！ / 2 逃げて！ / 3 外に出て！」の 3 ボタン（今の位置）。押す／1・2・3 キーで `selected_phrase` を変える
  - ステージ3（配信）: 「1 後ろに誰かいる！ / 2 左の壁に何かいる！ / 3 逃げて！」の 3 ボタン。押す／1・2・3 キーで `selected_phrase` を変える
- ボタンのロック表示（`lock_left` 中は押せない）は、**選択ボタンには適用しない**（選ぶのは、いつでもできる）。ロック中の警告は、`_on_warn`／`_on_comment` 側が無視するので、クリックしても何も起きない（ロックの表示 `lock_label` はそのまま出る）
- 難易度ごとの伝え方の強さ（`PHRASE_BONUS`）は、選んだ伝え方で今までどおり

### 4. 文言（ヒント）
- 通話（ステージ1）: 「怪しいものを、クリック！ 見えないうちにクリックすると信頼を失います。」
- 疑り深い相手: 「話しかけて（Enter）信頼をためてから、伝え方を選び（1・2・3）、怪しいものをクリック。「逃げて！」が一番強い。」
- 配信: 「伝え方を選び（1・2・3）、映像の怪しいものをクリックして警告コメント。映る前に騒ぐと荒らし扱い。同じ警告を%d回、%d秒以内に。」
- 誤警告のヒント文の「警告しよう」「見えてから」は、「クリックしよう」に合わせて言い換える
- タイトル画面の説明（`intro`）とフッターの文言も、「クリックで警告」に合わせて直す。フッター: `Esc: 一時停止・音量　1・2・3: 伝え方　クリック: 危険を警告　F11: 全画面`

## テスト
- `tests/test_logic.gd`・`tests/test_playthrough.gd` の既存のテスト・ボットは、`_set_mark` + `_on_warn`、`_on_comment(i)` を直接呼んでいる。**これらは、そのまま動くこと**（既存の関数を残すため）。変更は、人影が映っている場所を指している箇所を、必要なら `ghost_box_now()` に合わせる程度
- 新規（`tests/test_logic.gd` の末尾の `quit(...)` の直前）:
  - stage1: `at(m, 60.0)` のあと `m._on_video_click(m.ghost_box_now().get_center())` → `m.state == m.State.SAVED`（1 クリックで救出）。別の `fresh()` で `m._on_video_click(Vector2(50, 50))`（人影のいない場所）→ 救出にならず `false_alarms == 1`
  - stage1 で、人影が映る前（`at(m, 5.0)`）に人影の位置を `_on_video_click` → 誤警告 1 回
  - stage2: `selected_phrase = 1`、`at(m, 70.0)` のあと、`_on_video_click(ghost_box_now().get_center())` → 救出（「逃げて！」の効果を使う）。`selected_phrase = 0` では、同じ状況で救出にならない（信頼が足りず流される）ことを、もう 1 つの `fresh()` で確かめる（`at(m, 65.0)` など、既存の「信頼が足りないと流される」テストと同じ時刻を使う）
  - stage3（配信）: `at(m, 60.0)`、人影の位置を `_on_video_click` で 3 回（`lock_left` が 0 のときだけ。1 秒ずつ `_process`）→ 救出。人影のいない場所を `_on_video_click` すると誤警告（荒らし扱い）
  - 伝え方の選択: `_select_phrase(2)` を作り、`selected_phrase == 2` になる（範囲外の値は無視）。ステージ1で `_select_phrase(1)` を呼んでも、`selected_phrase` は 0 のまま（伝え方が 1 つのステージ）
  - Space: `m._unhandled_key_input(...)` ではなく、関数 `_on_warn` が Space では呼ばれないことは、キー処理のコードを読んで確認し、報告に書く（テストは不要）
- ボット（`tests/test_playthrough.gd`）: 名人ボットは、これまでの関数経由のまま。新規で、**クリック経由の名人ボット**（通話は `_on_video_click` で人影を 1 回、疑り深い相手は話しかけて信頼をためてから `selected_phrase = 1` でクリック、配信は 1 秒おきに人影をクリック）を足し、全ステージ × 全難易度で救出できること
