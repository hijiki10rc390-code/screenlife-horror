# 午後の自律開発プラン（〜18:00 まで）

作成: 2026-10-05。ユーザー不在の間に、確認なしで進めてよい範囲だけを進める。

## ゴール（18時に見せるもの）

「複数の通話と配信」に近づいた、遊べる版。具体的には次の3つ。
1. 通話を2つ続けて遊べる（1つ目を救出すると2つ目へ）
2. 配信パートの試作（コメント欄が流れ、配信者の背後に異変が出る）
3. 見た目（キャラ・部屋）を **1コマンドで差し替えられる仕組み**（外見は後から変える前提）

## 順序と時間配分

| 時間 | 作業 | 成果物 |
|---|---|---|
| 13:00〜14:15 | A. ステージを設定ファイルで動く形にする | `stages/*.json`、`main.gd` の改修、テスト追加 |
| 14:15〜15:15 | B. 素材パック生成を自動化する | `build_stage.py`（背景→人影→表情→重ね画像を一括生成） |
| 15:15〜16:30 | C. 配信パートの試作 | コメント欄・視聴者数・配信者の背後の異変 |
| 16:30〜17:20 | D. 警告の伝え方の選択と「信じてもらえない」 | 選択肢UI、結果の分岐、テスト |
| 17:20〜18:00 | E. まとめ | GIF/PNG、`AI_TODO.md` と引き継ぎ書の更新、`outputs/share/` に保存 |

遅れた場合は D を削り、A・B・C を優先する。

## 各作業の中身

**A. ステージ設定化**: いま `main.gd` に直接書いてある次の値を、ステージごとの JSON に移す。画像のパス、人影の範囲、人影の濃さの時間割、台詞、制限時間、効果音の時刻。救出したら次のステージへ進み、最後はエンディング。テストは「ステージ2へ進む」「全ステージ後にエンディング」を追加。

**B. 素材の自動生成**: 人物の指定（見た目の文章）と部屋の指定を設定に書けば、背景・人影・3段階の表情・重ね画像を順番に生成する。GPU は1本ずつ（同時実行しない）。外見を変えたいときは、設定の文章を直して実行するだけにする。2つ目の通話の素材もこれで作る。

**C. 配信パート**: 画面を配信視聴の見た目にする（映像、コメント欄、視聴者数）。コメントが時間とともに流れる。プレイヤーは異変の場所を指してコメントで警告する。配信者は、同じ警告が複数のコメントで続くと気づく仕組みを試す（1件目の試作は簡易版でよい）。

**D. 伝え方の選択**: 警告に「後ろ！」「逃げて」「通報して」から選ぶ。相手が最初は信じない設定を入れ、場面で効く選択肢が変わる。

## 守ること

- **外向きの操作はしない**: GitHub への push、公開、削除、課金。`git commit` もユーザーが求めるまでしない
- **GPU の生成は1本ずつ**: 同時に走らせるとメモリ不足で停止する（午前に発生）
- **トークン節約**: 画像の確認は一覧の1枚にまとめて見る。台詞などの文章下書きは Qwen（qwen3:8b）に任せ、手直しして使う。Qwen のコードレビューは誤指摘が多いので使わない。使用率が高いとの指示が出たら、引き継ぎ書を作って MiniMax に渡す
- **未確認を未確認と書く**: 音の聞こえ方、ゲームの面白さ、怖さの評価は私には確認できない。記録には「未確認」と残す
- **年齢**: 人物は明確に成人の見た目にする。若く見える指定は使わない
