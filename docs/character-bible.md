# Character Bible（キャラクター設定集）

> 2026-10-05 作成。決定の経緯は `docs/character-direction.md` の原則に従う。
> 変えるときは、変えた日付と理由をここに追記する。

## 全体方針

- 3 ステージそれぞれ別の女の子（既存の構成を維持）
- 全員 **成人**。23〜24 歳。年齢詐称なし
- 服装は **部屋着**（キャミソール + パンツ）、カメラは中距離
- ヘッドセットは全キャラクター共通（小物の固定で「同一人物感」を補強）
- 露骨な性的描写はなし。顔と表情の魅力で「守りたい」を引き出す
- 実在人物には似せない

## 表情の選択（stage2 の `outputs/stages_build/stage2/` 配下から）

`docs/character-direction.md` の方針と、`outputs/stages_build/stage2/sheet_faces.png` の 15 枚を確認した上で決定。

| 用途 | ファイル | 理由 |
|---|---|---|
| 通常 | `react_top.texture` のベース | 既存 |
| 笑顔 | `face_smile_40.png` | 白いキャミソール・ヘッドセット・自然な笑顔。微笑みの強さがちょうどいい |
| 恐怖 | **未充足**。`build_stage.py faces` で強い恐怖を 1 枚追加生成する（プロンプト案: `wide frightened eyes, mouth open in a scream, hands raised, head leaning back, dramatic expression`） | 既存 `face_fear_40/41` は「不安」止まりで、計画 05 の襲いかかり時に迫力不足 |
| ゲームオーバー（絶望） | `face_despair_41.png` | 目を見開き、口をわずかに開き、絶望感が強い |
| ハッピーエンド | `face_happy_41.png` | 片手を上げて手を振っている。配信の「ありがとう」感 |
| 照れ | `face_shy_40.png` | 頬を赤くして俯き加減。信頼度が十分高いときの返し |
| ウインク | `face_wink_40.png` | おまけ。台詞との対応で使う |

## キャラクター

### Mika（stage1・通話）

- **年齢**: 24 歳。会社員
- **見た目**: 髪は明るいライトブラウンのポニーテール。キャミソール + ドルフィンパンツ。猫耳ヘッドセット
- **口調**: 明るいタメ口。「ねー」「だよ」「えっ」多用
- **性格**: フレンドリー。ちょっと天然。悪気なく話題を振る
- **目的（物語）**: 夜遅く友達と雑談中。背後の異変に気づいていない
- **救出時の変化**: 笑顔になって「助かった〜！」と安堵する

### Aoi（stage2・疑り深い通話）

- **年齢**: 23 歳。フリーのデザイナー
- **見た目**: 髪は長いライトブラウン。キャミソール（レース付き）。白いヘッドセット
- **口調**: 柔らかい。語尾に「〜かな」「〜だよね」を残す。一人称「あたし」
- **性格**: 寂しがり。警戒心が強いが、信頼がたまると甘えてくる
- **目的（物語）**: 一人暮らしの夜。誰かと話したかった。背後の異変に気づいていない
- **救出時の変化**: 照れ笑い。「ありがと… もうちょっと話していたかったな」

### ゆめ（stage3・配信）

- **年齢**: 24 歳。配信者
- **見た目**: 髪はミディアム、ライトブラウン。キャミソール（スポーツブラ型）。白いヘッドセット
- **口調**: 配信スタイル。「みんな〜」「ありがと！」「えっ」多用。絵文字多め（コメント欄）
- **性格**: 明るい。視聴者との距離感がうまい。緊張すると早口になる
- **目的（物語）**: 夜の雑談配信。視聴者とのやりとり中。背後の異変に気づいていない
- **救出時の変化**: 視聴者に向けて手を振る（ハッピーエンド）

## 名前について

- 引き継ぎ書の既定「Aoi」を stage2 に採用。stage1「Mika」/stage3「ゆめ」は既存
- ユーザーから「3 人とも別の名前にして」と指示があれば変更する
- 漢字の表記は `stages/stage*.json` の `friend` キーで管理

## 台詞の口調

- `stages/stage*.json` の `idle`、`doubt`、`saved_line`、`trust_lost_line`、`miss_wrong`、`miss_unseen` を、Mika / Aoi / ゆめ それぞれに合わせて微調整する余地がある（未着手）
- 現状は stage2.json の台詞が Aoi 用に最適化されている

## 衣装の追加案（計画 09 以降）

- 好感度（信頼度）が十分高いとき、キャラが**パジャマ**に着替える（季節感）
- 配信のときは**別衣装**（パーカーなど）
- 衣装差分の生成は `build_stage.py` に `outfit` 工程を追加する形で対応

## 制作メモ

- 表情の選び方は「実際にゲームの流れで違和感がないか」を最優先（美人でも方向違いの表情は使わない）
- 強い恐怖（`fear` の強調版）は、計画 05 の襲いかかりのあと一瞬だけ映す。長く出すと怖い体験にならない
- 既存の `face_fear_40/41` は「不安」として使う（人影を気にし始めた段階）
