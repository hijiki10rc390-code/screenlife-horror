# Character Bible（キャラクター設定集）

> 2026-10-05 初版作成、2026-10-06 大幅追記。決定の経緯は `docs/character-direction.md` の原則に従う。
> 変えるときは、変えた日付と理由をここに追記する。

## 全体方針

- 3 ステージそれぞれ別の女の子（既存の構成を維持）
- 全員 **成人**。23〜24 歳。年齢詐称なし
- 服装は **部屋着**（キャミソール + パンツ）、カメラは中距離
- ヘッドセットは全キャラクター共通（小物の固定で「同一人物感」を補強）
- 露骨な性的描写はなし。顔と表情の魅力で「守りたい」を引き出す
- 実在人物には似せない

## 性格の三軸（3 キャラの差別化）

| 軸 | Mika | Aoi | ゆめ |
|---|---|---|---|
| 距離感 | 友達感覚（フラット） | 警戒→甘え（段階変化） | 公私の中間（ファン対応） |
| 反応速度 | 即座に反応 | 遅れて反応（考える） | 反射的に反応 |
| 感情の出し方 | 表情に出やすい | 表情に出しにくい | 大きく表現する |

## キャラクター

### Mika（stage1・通話）

- **年齢**: 24 歳。会社員
- **見た目**: 髪は明るいライトブラウンのポニーテール。キャミソール + ドルフィンパンツ。猫耳ヘッドセット
- **口調**: 明るいタメ口。「ねー」「だよ」「えっ」多用
- **一人称**: 「わたし」「あたし」が不定期に出る（気分で）
- **二人称**: 「ねー」「○○ちゃん」（名前呼び多め）
- **性格**: フレンドリー。ちょっと天然。悪気なく話題を振る
- **判断パターン**:
  - 警告 → 最初は疑うが、2 回続くと信じる
  - 不安 → 「えっ？なに？」と聞き返す
  - 怖い → 「やだ」「やめて」と短く言う
- **よく使う言葉・フレーズ**:
  - 「ねー聞いて聞いて」
  - 「やだなぁ」
  - 「えっ、なにそれ」
  - 「ほんとにぃ？」
  - 「ありがと〜！」
- **目的（物語）**: 夜遅く友達と雑談中。背後の異変に気づいていない
- **救出時の変化**: 笑顔になって「助かった〜！」と安堵する
- **失敗時の変化**: 「えっ、なんで…」と困惑（混乱型）

### Aoi（stage2・疑り深い通話）

- **年齢**: 23 歳。フリーのデザイナー
- **見た目**: 髪は長いライトブラウン。キャミソール（レース付き）。白いヘッドセット
- **口調**: 柔らかい。語尾に「〜かな」「〜だよね」を残す。一人称「あたし」
- **一人称**: 「あたし」（一貫）
- **二人称**: 「あなた」「○○さん」（丁寧寄り）
- **性格**: 寂しがり。警戒心が強いが、信頼がたまると甘えてくる
- **判断パターン**:
  - 警告 → 信頼が貯まるまで疑う（最大 3 回）
  - 不安 → 「…うそ」 と小声で
  - 怖い → 「やめて…怖いよ…」
- **よく使う言葉・フレーズ**:
  - 「ほんとに？」
  - 「…うそ」
  - 「もうちょっとだけ…」
  - 「ありがと…」
  - 「なになに？」
- **目的（物語）**: 一人暮らしの夜。誰かと話したかった。背後の異変に気づいていない
- **救出時の変化**: 照れ笑い。「ありがと… もうちょっと話していたかったな」
- **失敗時の変化**: 「…もう、知らない」（諦め型）

### ゆめ（stage3・配信）

- **年齢**: 24 歳。配信者
- **見た目**: 髪はミディアム、ライトブラウン。キャミソール（スポーツブラ型）。白いヘッドセット
- **口調**: 配信スタイル。「みんな〜」「ありがと！」「えっ」多用。絵文字多め（コメント欄）
- **一人称**: 「わたし」「ゆめ」（視聴者向けには「ゆめ」）
- **二人称**: 「みんな」「○○くん/ちゃん」
- **性格**: 明るい。視聴者との距離感がうまい。緊張すると早口になる
- **判断パターン**:
  - 警告 → 視聴者の反応を見て判断（自分の判断は遅い）
  - 不安 → 「えっ、ちょ…」と語尾が途切れる
  - 怖い → 「やだやだやだ！」
- **よく使う言葉・フレーズ**:
  - 「みんな〜！」
  - 「ありがと！」
  - 「えっ、ちょ、待って」
  - 「やば」
  - 「いぇい！」
- **目的（物語）**: 夜の雑談配信。視聴者とのやりとり中。背後の異変に気づいていない
- **救出時の変化**: 視聴者に向けて手を振る（ハッピーエンド）
- **失敗時の変化**: 「えっ、嘘でしょ…」（パニック型）

### 衣装選択の UI 統合（2026-10-06 完了）

タイトル画面に衣装選択セクションを追加（**デフォルト / パジャマ / パーカー** の 3 ボタン）。

- 選択した衣装は `user://settings.cfg` の `[visual] outfit` に保存
- 次回起動時に復元
- 衣装画像は全パターン事前ロード（`_build_scene_viewport` で `outfit_layers` を作成）
- 切替は表示の on/off だけなので高速

**実装場所**:
- `main.gd:_build_title_screen()` に衣装セクション追加
- `main.gd:_set_outfit(name)` で表示切替 + 設定保存
- `main.gd:_refresh_outfit_btns()` で選択中ボタンを明るく
- `main.gd:_build_scene_viewport()` で全衣装レイヤーを初期化

**assets/stages/ への衣装画像配置**:
- `outfit_pajamas.png` (各ステージ)
- `outfit_hoodie.png` (各ステージ)
- `.import` ファイルは自動生成

**stages/*.json への追加**:
```json
"outfits": {
  "default": "res://assets/.../base.png",
  "pajamas":  "res://assets/.../outfit_pajamas.png",
  "hoodie":   "res://assets/.../outfit_hoodie.png"
}
```

### 衣装アンロック（2026-10-06 追加）

衣装は **信頼度が一定以上に達したら解放** される方式。

- `pajamas`: `max_trust_reached >= 0.6` で解放
- `hoodie`:  `max_trust_reached >= 0.85` で解放
- `default`: 常に解放
- `max_trust_reached` は `_finish` 内で `belief` の最高到達点で更新し、`user://settings.cfg` の `[progress] max_trust` に保存
- ロック中の衣装ボタンは `disabled = true` で `modulate = (0.45, 0.45, 0.45)`（暗い灰色）
- 終了画面で新規アンロックされると「○○解放！」が表示される

### 衣装専用表情（2026-10-06 追加）

衣装ごとに専用の kawaii 表情を切り替える。衣装差分でキャラの世界観を保つ目的。

- `stages/<id>.json` の `assets.outfit_expressions` に `pajamas` / `hoodie` 用の表情画像を指定
- `_set_outfit(name)` で `react_tex["kawaii"]` を専用画像に差し替え。`default` に戻すと元に戻る
- 現状は stage2 のみ（`outfit_sleepy.png` = pajamas / `outfit_casual.png` = hoodie）
- stage1 / stage3 は未対応（衣装本体は生成済み）

**生成設定**: `stages_src/stage2_outfit_faces.json` / `stages_src/stage2_hoodie_faces.json`（`build_stage.py faces` で処理）

## 制作メモ

- 表情の選び方は「実際にゲームの流れで違和感がないか」を最優先（美人でも方向違いの表情は使わない）
- 強い恐怖（`fear` の強調版）は、計画 05 の襲いかかりのあと一瞬だけ映す。長く出すと怖い体験にならない
- 既存の `face_fear_40/41` は「不安」として使う（人影を気にし始めた段階）
- 3 キャラの差別化は **性格の三軸**（距離感・反応速度・感情の出し方）で担保する。衣装・髪型で差別化しすぎない
