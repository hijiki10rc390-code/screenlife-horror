# 設計メモ（たたき台 / 2026-10-04）

## コンセプト

プレイヤーは PC 画面の前に座っている。ビデオ通話や配信を見ていると、相手の背景に霊や犯罪者が映り込む。気づいて警告し、相手を救う。

## 基本ループ（縦の1本）

1. 通話開始。相手と雑談する（選択肢チャット）
2. 背景の異変が段階的に出る（物音 → 隅に影 → はっきり映る）
3. プレイヤーが気づいたら「警告」する（チャット / 定型文）
4. 相手が行動を選ぶ（振り向く / 部屋を出る / 通報 / 無視）
5. 結果が出る（救出 / 負傷 / 死亡）。気づくのが遅い・誤警告が続くと信頼が下がる

## 縦の1本の範囲

- 通話 1 回、約 5 分、相手 1 人、部屋 1 つ
- 異変は 3 種類（背景の影・窓の外・背後の人影）
- エンディング 2 種（救出 / 失敗）
- ここで「怖い」と感じられなければ、広げない

## 画面

- PC 風の横長デスクトップ。通話アプリのウィンドウが中心
- 相手の映像、チャット欄、警告ボタン
- 後で配信ウィンドウ（コメント欄・視聴者数）を追加

## 検証が必要なこと（最優先）

- 背景映像の作り方。静止画＋微小な動き、動画、自作の 2D のどれか
- 異変を「映り込ませる」手段（レイヤー合成、フレーム差し替え）
- 音（環境音・ノイズ・通話の音質劣化）。怖さの半分は音になる見込み
- 参考作品の画面と手触り（比較表を `references.md` に作る）

## 完了判定

実画面のスクリーンショットを目標画面と並べ、ユーザーが見て評価する。機能の有無では判定しない。
